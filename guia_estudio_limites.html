Bloque 1 — Concepto central

¿Qué es un límite y por qué existe?

El límite es la respuesta a esta pregunta: ¿hacia qué valor se dirige f(x) cuando x se acerca a un punto c? No importa si f(c) existe o no. Lo que importa es el comportamiento de la función en los alrededores de ese punto.

Analogía — el GPS y el semáforo en rojo

Imagina que vas conduciendo hacia un cruce y el semáforo está en rojo. Tu GPS calcula tu velocidad en ese instante aunque tú aún no hayas llegado al cruce. Eso es el límite: mide lo que estaba pasando mientras te acercabas, no lo que ocurre cuando ya estás detenido ahí.

En matemáticas: el límite de f(x) cuando x → c mide hacia dónde va la función mientras x se acerca a c. Lo que valga f(c) exactamente es una pregunta aparte.

Figura 1. Desde ambos lados, f(x) converge al mismo valor L cuando x → c, aunque f(c) no exista (hueco en la curva).

Notación oficial lím f(x) = L x → c

Se lee: "el límite de f de x cuando x tiende a c es L". La flecha → significa «se acerca», no «llega».

Bloque 2 — Métodos de cálculo

¿Cómo se calcula un límite? Dos métodos

Método 1 — Sustitución directa

Si al sustituir x = c en f(x) el resultado es un número definido (no hay 0/0), ese número ES el límite.

Cuándo usarlo

Siempre que f(c) exista y sea un número real. Funciona en polinomios y funciones lineales.

Figura 2. Función continua: la sustitución directa en x = 2 da f(2) = 11, que es exactamente el límite.

Método 2 — Tabla de valores numéricos

Cuando la sustitución da 0/0, se evalúa f(x) con valores cada vez más cercanos a c desde ambos lados y se observa hacia dónde converge.

Cuándo usarlo

Cuando aparece 0/0. Usa valores: c − 0.1, c − 0.01, c − 0.001 y c + 0.001, c + 0.01, c + 0.1.

Figura 3. f(x) = (x² − 9)/(x − 3) tiene hueco en x = 3, pero la tabla confirma que el límite vale 6.

Bloque 3 — Ejemplos resueltos

Los cinco ejercicios de clase, resueltos paso a paso

Ejercicio 1 — lím (5x − 3) cuando x → 2
f(x) = 5x − 3. ¿Cuál es el límite cuando x → 2?
  • 1Sustitución directa: f(2) = 5(2) − 3 = 10 − 3 = 7. Resultado definido.
  • 2El límite existe y vale 7.
lím (5x − 3) = 7 cuando x → 2

Figura 4. f(x) = 5x − 3 pasa por (2, 7). Función continua: límite = valor de la función.

Ver en Desmos: f(x) = 5x − 3, punto (2, 7)
Ejercicio 2 — lím (x² + 2x) cuando x → 3
f(x) = x² + 2x. ¿Cuál es el límite cuando x → 3?
  • 1Sustitución directa: f(3) = (3)² + 2(3) = 9 + 6 = 15. Resultado definido.
  • 2El límite existe y vale 15.
lím (x² + 2x) = 15 cuando x → 3

Figura 5. La parábola f(x) = x² + 2x en x = 3 vale 15. Límite = 15.

Ver en Desmos: f(x) = x² + 2x, punto (3, 15)
Ejercicio 3 — lím (x² − 9)/(x − 3) cuando x → 3
Este es el ejercicio clave. Sustitución directa da 0/0. Se usa la tabla.
  • 1Sustitución: f(3) = (9−9)/(3−3) = 0/0. La sustitución directa falla.
  • 2Construyo la tabla con valores cercanos a x = 3 desde ambos lados.
x2.52.92.99→ 3 ←3.013.13.5
f(x) 5.55.95.99 → 6 6.016.16.5
  • 3Por la izquierda: 5.5 → 5.9 → 5.99 → se acerca a 6.
  • 4Por la derecha: 6.5 → 6.1 → 6.01 → también se acerca a 6.
  • 5Ambos lados convergen a 6. El límite existe y vale 6. f(3) no existe pero el límite sí.
lím (x² − 9)/(x − 3) = 6 cuando x → 3 · f(3) = 0/0, no existe

Figura 6. f(x) = (x² − 9)/(x − 3) es igual a y = x + 3 para todo x ≠ 3. Hueco en (3, 6), límite = 6.

Ver en Desmos: Hueco en (3, 6) — lím = 6
Ejercicio 4 — lím (2x² − 1) cuando x → 0
f(x) = 2x² − 1. ¿Cuál es el límite cuando x → 0?
  • 1Sustitución directa: f(0) = 2(0)² − 1 = 0 − 1 = −1. Resultado definido.
  • 2El límite existe y vale −1.
lím (2x² − 1) = −1 cuando x → 0

Figura 7. La parábola f(x) = 2x² − 1 tiene su vértice en (0, −1). El límite cuando x → 0 es −1.

Ver en Desmos: Vértice (0, −1) — lím = −1
Ejercicio 5 — Aplicación informática: lím M(n) = n² + 3 cuando n → 2
M(n) = n² + 3 MB de memoria (n = número de procesos). ¿Cuál es el límite cuando n → 2?
  • 1Identifico: M(n) = n² + 3. Límite cuando n → 2.
  • 2Sustitución: M(2) = (2)² + 3 = 4 + 3 = 7. Resultado definido.
  • 3El límite existe y vale 7 MB.
  • 4Interpretación: cuando el sistema se acerca a 2 procesos simultáneos, el consumo de memoria converge a 7 MB.
lím M(n) = 7 MB cuando n → 2

Figura 8. M(n) = n² + 3 es continua. Cuando n → 2, el consumo de memoria converge suavemente a 7 MB.

Para recordar

Puntos clave de la evaluación

  • El límite describe hacia dónde se dirige f(x), no dónde está. La diferencia entre el límite y el valor de la función es la distinción más importante de esta unidad.
  • Intenta siempre la sustitución directa primero. Si f(c) da un número definido, ese es el límite. Solo si sale 0/0 cambias de método.
  • La tabla se construye desde ambos lados. Si por la izquierda y por la derecha convergen al mismo valor, el límite existe.
  • La notación importa. Escribe siempre "lím f(x) =" con "cuando x → c". No basta con el número solo.
  • El contexto informático es parte de la evaluación. Interpreta el resultado en términos reales, no solo matemáticos.
