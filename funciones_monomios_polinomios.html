Funciones, Monomios y Polinomios

Definición, estructura, clasificación y aplicaciones en el contexto de la programación y los sistemas computacionales

Bloque 1

Funciones

¿Qué es una función?

Una función es una regla que toma un valor de entrada y produce exactamente un valor de salida. Nada más, nada menos. La clave está en esa palabra: exactamente uno. Si un valor de entrada puede producir dos salidas distintas, ya no es una función.

Definición formal

Una función f de un conjunto A a un conjunto B es una regla que asigna a cada elemento x del dominio A exactamente un elemento f(x) del codominio B.

f : A → B f(x) = expresión

Se lee: "f de x". La x es la variable independiente (entrada). El valor f(x) es la variable dependiente (salida). El dominio A es el conjunto de entradas permitidas.

Piénsalo como una máquina: metes un número por un lado, la máquina ejecuta una operación, y te devuelve exactamente un número por el otro lado. Si la máquina pudiera darte dos respuestas distintas para la misma entrada, no sería una función; sería un comportamiento no determinista, algo que en programación llamaríamos un error.

Función vs. relación que no es función

Expresión ¿Es función? Razón
f(x) = 2x + 1 Sí A cada x le corresponde exactamente un valor: x = 3 da f(3) = 7, siempre.
f(x) = x² Sí Aunque f(2) = 4 y f(−2) = 4, a cada x le corresponde un único resultado.
x² + y² = 25 No Para x = 3 hay dos valores de y: y = 4 y y = −4. Una entrada produce dos salidas.
f(x) = 1/x Sí (con restricción) Es función para todo x distinto de 0. En x = 0 no está definida, por eso el dominio excluye el cero.

Dominio y rango

El dominio es el conjunto de todos los valores de x que la función acepta como entrada. El rango es el conjunto de todos los valores que la función puede producir como salida. Siempre se definen en contexto: un modelo matemático puede tener dominio infinito, pero si representa tiempo, el dominio real es t ≥ 0.

Dominio

f(x) = 2x + 3 → Dominio: todos los reales ℝ f(x) = 1/x → Dominio: x ≠ 0 f(x) = √x → Dominio: x ≥ 0

Rango

f(x) = 2x + 3 → Rango: todos los reales ℝ f(x) = x² → Rango: y ≥ 0 f(x) = √x → Rango: y ≥ 0
Explorar dominio y rango visualmente: f(x) = 2x+3, x² y √x

Evaluación de una función

Evaluar f(x) en un valor concreto significa sustituir x por ese número y calcular el resultado. Es la operación más básica y la más usada: cada vez que un programa llama a una función con un argumento, está evaluando f en ese valor.

Ejemplo — Evaluación básica paso a paso
Sea f(x) = 3x² − 2x + 1. Calcula f(0), f(2) y f(−1).
  • 1 f(0): sustituyo x = 0.
    f(0) = 3(0)² − 2(0) + 1 = 0 − 0 + 1 = 1
  • 2 f(2): sustituyo x = 2.
    f(2) = 3(2)² − 2(2) + 1 = 3(4) − 4 + 1 = 12 − 4 + 1 = 9
  • 3 f(−1): sustituyo x = −1.
    f(−1) = 3(−1)² − 2(−1) + 1 = 3(1) + 2 + 1 = 3 + 2 + 1 = 6
f(0) = 1  ·  f(2) = 9  ·  f(−1) = 6

Ejemplo informático 1 — Descarga de datos
La cantidad de datos descargados (en MB) está dada por D(t) = 50t, donde t es el tiempo en minutos.
  • 1 ¿Cuántos MB se descargan en 2 minutos?
  • 2 ¿Cuántos MB se descargan en 5 minutos?
  • 3 ¿En cuántos minutos se habrán descargado 350 MB?
Ver solución
  • 1 D(2) = 50 · 2 = 100 MB
  • 2 D(5) = 50 · 5 = 250 MB
  • 3 50t = 350  →  t = 350 / 50 = 7 minutos
D(t) = 50t  ·  D(2) = 100 MB  ·  D(5) = 250 MB  ·  t = 7 min para 350 MB

Ejemplo informático 2 — Consumo de memoria RAM
Un proceso en ejecución consume memoria según M(n) = 4n + 16 MB, donde n es el número de hilos activos. El sistema tiene un límite de 128 MB disponibles para ese proceso.
  • 1 ¿Cuánta memoria usa el proceso con 5 hilos activos?
  • 2 ¿Cuánta memoria usa con 10 hilos?
  • 3 ¿Cuántos hilos puede lanzar sin superar el límite de 128 MB?
Ver solución
  • 1 M(5) = 4(5) + 16 = 20 + 16 = 36 MB
  • 2 M(10) = 4(10) + 16 = 40 + 16 = 56 MB
  • 3 4n + 16 ≤ 128  →  4n ≤ 112  →  n ≤ 28. El proceso puede tener hasta 28 hilos sin superar el límite.
M(5) = 36 MB  ·  M(10) = 56 MB  ·  máximo 28 hilos

Monomios

¿Qué es un monomio?

Un monomio es la expresión algebraica más simple: un solo término formado por un coeficiente numérico multiplicado por una o más variables elevadas a exponentes enteros no negativos. No tiene sumas ni restas; es un producto.

Elemento Descripción En el ejemplo −6x³y²
Coeficiente El factor numérico del monomio. Puede ser entero, fraccionario o irracional. −6
Variable(s) Las letras que representan valores desconocidos. x e y
Exponentes Los valores a los que están elevadas las variables. Siempre enteros no negativos. 3 (en x) y 2 (en y)
Grado La suma de todos los exponentes del monomio. 3 + 2 = 5

Monomios semejantes

Dos monomios son semejantes cuando tienen exactamente las mismas variables con exactamente los mismos exponentes. Solo los monomios semejantes pueden sumarse o restarse; los que no son semejantes no pueden combinarse, igual que no puedes sumar manzanas con kilómetros.

Semejantes
3x² y −7x² son semejantes: ambos tienen x con exponente 2.
Su suma: 3x² + (−7x²) = (3 − 7)x² = −4x²
No semejantes
3x² y 5x³ no son semejantes: el exponente de x es distinto.
No se pueden combinar. La expresión 3x² + 5x³ no simplifica más.
Multiplicación
En la multiplicación no hace falta que sean semejantes. Se multiplican coeficientes y se suman exponentes de la misma variable.
(4x²)(3x⁵) = 12x⁷  ·  (2x³y)(−5xy²) = −10x⁴y³

Ejemplos resueltos — Monomios

Ejemplo — Identificar partes y grado
Para cada monomio, identifica el coeficiente, las variables, los exponentes y el grado: (a) 7x⁴, (b) −3a²b, (c) 9
  • a 7x⁴: coeficiente = 7, variable = x, exponente = 4, grado = 4.
  • b −3a²b: coeficiente = −3, variables = a y b, exponentes = 2 (en a) y 1 (en b, ya que b = b¹), grado = 2 + 1 = 3.
  • c 9: coeficiente = 9, sin variables, grado = 0. Un número solo es un monomio de grado cero (monomio constante).
Grados: 7x⁴ → 4  ·  −3a²b → 3  ·  9 → 0
Ejemplo — Suma y multiplicación de monomios
Resuelve: (a) 8x² + (−3x²) + x², (b) (2x³)(5x²), (c) (−4ab²)(3a²b)
  • a Los tres términos son semejantes (misma variable, mismo exponente). Sumo coeficientes: 8 + (−3) + 1 = 6  →  6x²
  • b Multiplico coeficientes: 2 · 5 = 10. Sumo exponentes de x: 3 + 2 = 5. Resultado: 10x⁵
  • c Coeficientes: (−4)(3) = −12. Exponentes de a: 1 + 2 = 3. Exponentes de b: 2 + 1 = 3. Resultado: −12a³b³
6x²  ·  10x⁵  ·  −12a³b³
Ejemplo informático 3 — Tiempo de respuesta de un servidor
El tiempo de respuesta de un servidor (en milisegundos) para procesar n peticiones simultáneas se modela con el monomio T(n) = 3n². Cada petición ocupa el mismo tiempo base, pero al haber más peticiones simultáneas el servidor las procesa en bloques cuadráticos.
  • 1 ¿Cuál es el tiempo de respuesta con 4 peticiones?
  • 2 ¿Cuál es el tiempo de respuesta con 10 peticiones?
  • 3 Si el tiempo máximo aceptable es 300 ms, ¿cuántas peticiones simultáneas puede manejar el servidor?
Ver solución
  • 1 T(4) = 3(4)² = 3(16) = 48 ms
  • 2 T(10) = 3(10)² = 3(100) = 300 ms
  • 3 3n² ≤ 300  →  n² ≤ 100  →  n ≤ 10. El servidor puede manejar como máximo 10 peticiones simultáneas.
T(4) = 48 ms  ·  T(10) = 300 ms  ·  máximo 10 peticiones

Polinomios

¿Qué es un polinomio?

Un polinomio es la suma de uno o más monomios. Cada monomio dentro del polinomio se llama término. Los polinomios son las funciones algebraicas más comunes en matemáticas e ingeniería: desde modelar la trayectoria de un objeto hasta describir la complejidad de un algoritmo.

Forma general de un polinomio en x P(x) = aₙxⁿ + aₙ₋₁xⁿ⁻¹ + ··· + a₁x + a₀

aₙ es el coeficiente líder (≠ 0), n es el grado del polinomio y a₀ es el término independiente. Los exponentes son enteros no negativos, escritos de mayor a menor.

Cómo determinar el grado de un polinomio

El grado de un polinomio es el mayor exponente que aparece en cualquiera de sus términos, una vez que el polinomio está simplificado. Determinar el grado correcto es fundamental porque el grado describe el comportamiento a largo plazo de la función.

Ejemplo
P(x) = 5x⁴ − 3x² + 7x − 2  →  grado = 4 (el mayor exponente es 4, en el primer término)
Ejemplo
Q(x) = −9x³ + x² − x + 11  →  grado = 3 (el mayor exponente es 3, aunque el coeficiente sea negativo)
Atención
Un polinomio puede estar desordenado: 4 + x² − 3x tiene grado 2, aunque el término de mayor grado no esté primero. Antes de determinar el grado, ordena de mayor a menor: −3x² + x − 4 (se reescribe con signo incluido en el coeficiente, grado = 2).

Evaluación de un polinomio

Evaluar un polinomio es exactamente igual que evaluar cualquier función: sustituir la variable por un valor concreto y operar respetando la jerarquía de operaciones (primero potencias, luego productos, luego sumas y restas).

Ejemplo — Evaluación de polinomio de grado 3
Sea P(x) = 2x³ − x² + 4x − 5. Calcula P(1), P(−2) y P(3).
  • 1 P(1):
    2(1)³ − (1)² + 4(1) − 5 = 2 − 1 + 4 − 5 = 0
    Nota: P(1) = 0 significa que x = 1 es una raíz del polinomio.
  • 2 P(−2):
    2(−2)³ − (−2)² + 4(−2) − 5 = 2(−8) − 4 − 8 − 5 = −16 − 4 − 8 − 5 = −33
  • 3 P(3):
    2(3)³ − (3)² + 4(3) − 5 = 2(27) − 9 + 12 − 5 = 54 − 9 + 12 − 5 = 52
P(1) = 0  ·  P(−2) = −33  ·  P(3) = 52

Suma y resta de polinomios

Para sumar o restar polinomios se agrupan los términos semejantes (misma variable, mismo exponente) y se suman o restan sus coeficientes. Los términos no semejantes simplemente permanecen por separado en el resultado.

Ejemplo — Suma y resta de polinomios
Dados P(x) = 3x³ − 2x² + x − 4 y Q(x) = x³ + 5x² − 3x + 7.
Calcula: (a) P(x) + Q(x) y (b) P(x) − Q(x).
  • a Suma:
    (3+1)x³ + (−2+5)x² + (1−3)x + (−4+7)
    = 4x³ + 3x² − 2x + 3
  • b Resta — distribuyo el signo negativo en Q(x):
    (3−1)x³ + (−2−5)x² + (1+3)x + (−4−7)
    = 2x³ − 7x² + 4x − 11
P+Q = 4x³ + 3x² − 2x + 3  ·  P−Q = 2x³ − 7x² + 4x − 11
Ver P, Q, P+Q y P−Q en la misma ventana: Abrir en Desmos
Ejemplo informático 4 — Complejidad de dos algoritmos
Un sistema ejecuta dos procesos de forma secuencial. El primero tiene complejidad temporal A(n) = 2n² + 3n y el segundo B(n) = n² − n + 5, donde n es el tamaño de la entrada. El tiempo total de ejecución es T(n) = A(n) + B(n).
  • 1 Calcula T(n) = A(n) + B(n) simplificado.
  • 2 ¿Cuánto tarda el sistema completo para n = 10?
  • 3 ¿Cuánto ahorra el sistema si se elimina el segundo proceso? Calcula A(10).
Ver solución
  • 1 T(n) = (2n² + 3n) + (n² − n + 5)
    = (2+1)n² + (3−1)n + 5
    = 3n² + 2n + 5
  • 2 T(10) = 3(10)² + 2(10) + 5 = 300 + 20 + 5 = 325 unidades de tiempo
  • 3 A(10) = 2(10)² + 3(10) = 200 + 30 = 230 unidades de tiempo
    Ahorro: 325 − 230 = 95 unidades, que es exactamente B(10) = 100 − 10 + 5 = 95.
T(n) = 3n² + 2n + 5  ·  T(10) = 325  ·  A(10) = 230
Ver A(n), B(n) y T(n) = A+B: Abrir en Desmos
Ejemplo informático 5 — Almacenamiento en una base de datos
El espacio de almacenamiento (en GB) que ocupa una base de datos después de t meses de operación está modelado por S(t) = 0.5t² + 2t + 1, donde t es el número de meses. Los primeros datos (en t = 0) ocupan 1 GB de espacio base.
  • 1 ¿Cuánto espacio ocupa la base de datos a los 4 meses?
  • 2 ¿Cuánto espacio ocupa a los 12 meses (1 año)?
  • 3 Identifica el grado del polinomio y explica qué tipo de crecimiento representa.
Ver solución
  • 1 S(4) = 0.5(4)² + 2(4) + 1 = 0.5(16) + 8 + 1 = 8 + 8 + 1 = 17 GB
  • 2 S(12) = 0.5(12)² + 2(12) + 1 = 0.5(144) + 24 + 1 = 72 + 24 + 1 = 97 GB
  • 3 Grado del polinomio = 2 (cuadrático). El crecimiento es cuadrático: el almacenamiento no crece de forma constante, sino que acelera con el tiempo. Esto indica que la base de datos requiere planificación de capacidad a mediano plazo.
S(4) = 17 GB  ·  S(12) = 97 GB  ·  Grado 2 — crecimiento cuadrático

Cierre de la sesión

Conclusión

Los tres conceptos trabajados hoy —función, monomio y polinomio— forman la base algebraica sobre la que se construye todo el cálculo diferencial. Las ideas clave que deben quedar consolidadas son:

  • Una función es una regla de asignación única. Lo que define a una función no es su forma algebraica, sino la propiedad de que a cada entrada le corresponde exactamente una salida. Esta unicidad es el fundamento de cualquier modelo computacional determinista.
  • Un monomio es el bloque de construcción más simple del álgebra. Tiene un coeficiente, una o más variables y exponentes enteros no negativos. Su grado es la suma de todos sus exponentes. Solo los monomios semejantes pueden sumarse o restarse directamente.
  • Un polinomio es una suma de monomios y describe una amplia variedad de comportamientos. Su grado determina cuántas veces puede cambiar de dirección la gráfica y cómo se comporta para valores muy grandes de x. Los polinomios de grado 1 son lineales, los de grado 2 son cuadráticos, y así sucesivamente.
  • Evaluar una función o polinomio es la operación más fundamental en modelado. Sustituir el valor de la variable y calcular el resultado es exactamente lo que hace un programa cada vez que llama a una función con un argumento concreto. Dominar esta mecánica es el primer paso para resolver cualquier problema de modelado real.
  • Los polinomios aparecen en sistemas computacionales en todas partes. La complejidad algorítmica O(n²), el consumo de memoria, el crecimiento de datos almacenados y los modelos de latencia son ejemplos directos. Reconocer la forma polinomial de un fenómeno permite predecir su comportamiento futuro con solo evaluar la función en el valor deseado.
