Límites Algebraicos

Cómo resolver límites cuando la sustitución directa falla — factorización, cancelación y racionalización con aplicaciones en sistemas computacionales

Duración60 minutos
AsesorMtro. José Armando Vera Rodríguez
Propósito de la sesión

Competencias a desarrollar

01 Reconocer cuándo la sustitución directa falla e identificar la forma indeterminada que aparece (0/0) como señal de que se requiere un método algebraico.
02 Aplicar factorización y cancelación de factores para simplificar expresiones racionales antes de evaluar el límite.

La clase del 4 de julio estableció qué es un límite y cómo estimarlo con tablas. Hoy aprendemos a calcularlo exactamente cuando la sustitución directa produce 0/0. Ese es el salto de "estimar" a "resolver".

1

¿Dónde quedamos? El problema de 0/0

En la clase anterior calculamos cinco límites. Cuatro se resolvieron por sustitución directa. El quinto — lím (x² − 9)/(x − 3) cuando x → 3 — produjo 0/0 y tuvimos que estimarlo con la tabla. Hoy aprendemos a resolverlo exactamente, sin tabla.

Figura 1. f(x) = (x² − 9)/(x − 3) es idéntica a la recta y = x + 3, excepto en x = 3 donde tiene un hueco. El límite cuando x → 3 es 6. La tabla de la clase anterior nos dijo eso; hoy lo demostramos algebraicamente.

La idea central de hoy

Cuando aparece 0/0 es porque hay un factor que se repite en el numerador y en el denominador. Ese factor compartido es el culpable del hueco. Si lo identificamos y lo cancelamos, la expresión se simplifica a algo que sí podemos evaluar directamente.

Es como simplificar una fracción: 6/8 = 3/4 porque los dos comparten el factor 2. El resultado es diferente de escribir, pero representa la misma cantidad. Con límites ocurre lo mismo, pero en lugar de dividir entre 2, cancelamos el factor que produce el 0/0.

2

Las tres técnicas algebraicas para resolver 0/0

A

Factorización de diferencia de cuadrados

Cuando el numerador tiene la forma x² − a², se factoriza como (x + a)(x − a). Si el denominador contiene (x − a), ese factor se cancela y desaparece el 0/0.

Ejemplo: x² − 9 = (x + 3)(x − 3)  ·  x² − 25 = (x + 5)(x − 5)

B

Factorización de trinomio cuadrático

Cuando el numerador tiene la forma x² + bx + c, se buscan dos números que multiplicados den c y sumados den b. La expresión se reescribe como (x + r)(x + s) y el factor común con el denominador se cancela.

Ejemplo: x² − 5x + 6 = (x − 2)(x − 3)  porque (−2)(−3)=6 y (−2)+(−3)=−5

C

Factor común en el numerador

Cuando todos los términos del numerador comparten un factor con el denominador, se extrae ese factor al frente y se cancela. Útil cuando el numerador es una expresión simple como ax² + bx.

Ejemplo: (x² + 2x)/(x) = x(x + 2)/(x) = (x + 2)

Procedimiento general — aplica siempre en este orden
  1. Intenta sustitución directa. Si da un número definido, terminaste.
  2. Si da 0/0, factoriza el numerador y el denominador por separado.
  3. Cancela el factor que se repite en ambos lados.
  4. Aplica sustitución directa a la expresión simplificada.
  5. Verifica que el resultado tiene sentido con los valores de la tabla.

Ejemplos resueltos paso a paso

Ejemplo 1 — Diferencia de cuadrados: lím (x² − 9)/(x − 3) cuando x → 3 Técnica A
Este es el ejercicio pendiente de la clase anterior. Ya sabíamos por la tabla que el límite era 6. Ahora lo demostramos algebraicamente.
  • 1 Intento sustitución directa: f(3) = (9 − 9)/(3 − 3) = 0/0. Falla. Necesito factorizar.
  • 2 Factorizo el numerador usando diferencia de cuadrados:
    x² − 9 = x² − 3² = (x + 3)(x − 3)
  • 3 Reescribo la fracción con el numerador factorizado:
(x² − 9) / (x − 3) expresión original
= (x + 3)(x − 3) / (x − 3) factorizo el numerador
= (x + 3) · (x − 3) / (x − 3) cancelo el factor (x − 3)
= x + 3   para todo x ≠ 3 expresión simplificada
  • 4 Aplico sustitución directa a la expresión simplificada:
    lím (x + 3) cuando x → 3 = 3 + 3 = 6
  • 5 Verifico: la tabla de clase mostraba que f(x) → 6. Coincide. ✓
lím (x² − 9)/(x − 3) = 6   cuando x → 3

Ejemplo 3 — Trinomio cuadrático: lím (x² − 5x + 6)/(x − 2) cuando x → 2 Técnica B
Aquí el numerador no es una diferencia de cuadrados: hay que factorizar un trinomio. Buscamos dos números que multiplicados den 6 y sumados den −5.
  • 1Sustitución directa: f(2) = (4 − 10 + 6)/(2 − 2) = 0/0. Falla.
  • 2 Factorizo el trinomio x² − 5x + 6:
    Busco r y s tal que r · s = 6 y r + s = −5.
    r = −2, s = −3  → (−2)(−3) = 6 ✓  y (−2) + (−3) = −5 ✓
    Entonces: x² − 5x + 6 = (x − 2)(x − 3)
(x² − 5x + 6) / (x − 2)expresión original
= (x − 2)(x − 3) / (x − 2)factorizo el trinomio
= (x − 2)(x − 3) / (x − 2)cancelo
= x − 3   para todo x ≠ 2
  • 3Sustitución directa: lím (x − 3) = 2 − 3 = −1 cuando x → 2.
lím (x² − 5x + 6)/(x − 2) = −1   cuando x → 2

Ejemplo 4 — Aplicación informática: eficiencia de un algoritmo Técnica C + A
El tiempo promedio de ejecución por tarea de un algoritmo está modelado por: T(n) = (n² − n) / n, donde n es el número de tareas. Calcula el límite cuando n → 0 e interpreta el resultado.
  • 1Sustitución directa: T(0) = (0 − 0)/0 = 0/0. Falla.
  • 2 Factor común en el numerador:
    n² − n = n(n − 1)  → extrae el factor n.
(n² − n) / nexpresión original
= n(n − 1) / nfactor común en numerador
= n(n − 1) / ncancelo n
= n − 1   para todo n ≠ 0
  • 3Sustitución directa: lím (n − 1) = 0 − 1 = −1 cuando n → 0.
  • 4 Interpretación en sistemas: cuando el número de tareas se acerca a cero, el tiempo promedio por tarea tiende a −1. En un contexto real, un tiempo negativo indica que el modelo no es válido para n = 0 (no puede haber cero tareas en ejecución). El límite matemático existe, pero el ingeniero debe verificar que el dominio práctico es n ≥ 1.
lím (n² − n)/n = −1 cuando n → 0  ·  el modelo es válido solo para n ≥ 1

4

¿Qué cambia al factorizar? — Comparación visual

La pregunta más frecuente es: ¿si cancelamos un factor, estamos cambiando la función? La respuesta corta es no, pero conviene verlo gráficamente.

Figura 6. f(x) y g(x) son idénticas para todo x ≠ 3. La única diferencia es el punto x = 3: f tiene un hueco, g tiene un punto sólido. Para el cálculo del límite, esa diferencia no importa.

Por qué podemos cancelar sin problema

El límite cuando x → 3 pregunta qué pasa cuando x está cerca de 3, no cuando x es exactamente 3. Para todos los valores cercanos, f(x) = g(x). Por eso el límite de f y el límite de g son idénticos: la diferencia en un solo punto no cambia el comportamiento de acercamiento.

Cuando cancelamos (x − 3), simplemente estamos diciendo: "para calcular el límite, voy a usar la versión sin hueco, que es equivalente en todos los puntos que importan".

Cierre de la sesión

Conclusión

  • El 0/0 no es un error: es una señal. Indica que hay un factor compartido entre numerador y denominador que se puede cancelar. La aparición de 0/0 es el punto de partida del trabajo algebraico, no una señal de que el límite no existe.
  • Factorizar convierte lo insoluble en trivial. Después de cancelar el factor problemático, la expresión que queda siempre admite sustitución directa. El límite algebraico es en esencia: factoriza, cancela, sustituye.
  • Cancelar un factor no cambia el límite. La función con hueco y la función simplificada son idénticas en todos los puntos cercanos al problema. Para el límite, los valores en el punto exacto no importan; solo importa lo que pasa alrededor.
  • En sistemas computacionales, los modelos tienen dominio restringido. Un resultado matemáticamente válido puede carecer de sentido práctico. Siempre interpreta el límite en contexto: ¿es ese valor posible en el sistema real que estás modelando?
  • El flujo correcto es: tabla → álgebra → verificar. La tabla da la intuición del valor esperado. El álgebra lo demuestra exactamente. La comparación de ambos resultados confirma que no hubo errores de cálculo.
