2La idea: una variable auxiliar para simplificar

Mira esta integral: ∫ (3x + 2)4 dx. La tabla sabe resolver ∫ u4 du, pero aquí la base no es "x" sino "3x + 2". ¿Qué hacemos? Le ponemos un nombre más simple.

Analogía de programaciónEs igual que cuando refactorizas código: en lugar de repetir una expresión larga, la guardas en una variable auxiliar y trabajas con ella. Después del cálculo, "deshaces" el cambio y vuelves a tus variables originales.
# Idea de sustitución, escrita como código x = 1 u = 3*x + 2 # variable auxiliar: u = 3x + 2 resultado = u**5 / 15 # integral ya simple, en términos de u # al final se escribe en términos de x: (3x + 2)^5 / 15

¿De dónde sale? La regla de la cadena al revés

Derivar un paréntesis elevado a una potencia deja la derivada de "lo de adentro" multiplicando afuera. La sustitución hace el camino contrario: reconoce esa pieza que sobra y la absorbe en du.

Derivar (cadena)

d/dx [ (x2+1)4 ] = 4(x2+1)3 · 2x

Aparece 2x: la derivada de lo de adentro.

Integrar (sustitución)

∫ (x2+1)3 · 2x dx = (x2+1)44 + C

Si ves 2x junto al paréntesis, es la señal de que u = x2+1.

Ejemplo guiado: ∫ (3x + 2)4 dx

Paso 1
Elegimos u = 3x + 2Es lo que está dentro del paréntesis elevado a la potencia.
Paso 2
du = 3 dx  ⇒  dx = du3Derivamos u y despejamos dx para poder reemplazarlo.
Paso 3
∫ u4 · du3 = 13 ∫ u4 duEl 1/3 es una constante: puede salir de la integral.
Paso 4
13 · u55 = u515Regla de la potencia que ya conoces.
Paso 5
(3x + 2)515 + CSe sustituye u = 3x + 2 de regreso. Siempre se contesta en la variable original.
Verificar
d/dx = 5(3x+2)4 · 315 = (3x+2)4 ✓

Pistas para elegir u

Si ves...Entonces u =Ejemplo
Un paréntesis elevado a una potencialo del paréntesis(3x+2)4 → u = 3x+2
Algo dentro de sen, cos o e(...)el argumentocos(5x) → u = 5x

Regla de oroDespués de elegir u, todo lo que quede en la integral debe poder escribirse con u y du. Si sobra una "x" que no desaparece, probablemente elegiste otra u.

5Aplicaciones en Sistemas Computacionales

La sustitución aparece cada vez que una tasa depende de una expresión como 0.2t o 2t + 1. Revisemos tres escenarios.

Caso 1 · RedesDescarga que acelera con el tiempo
Situación
La velocidad de descarga de un archivo crece como v(t) = e0.2t MB/s, con t en segundos. Si al inicio hay 0 MB descargados, ¿cuántos MB habrá en t = 10 s?
Paso 1 y 2
u = 0.2t  ⇒  du = 0.2 dt  ⇒  dt = 5 du
Paso 3 y 4
∫ eu · 5 du = 5eu
Paso 5
D(t) = 5e0.2t + C
Constante
D(0) = 0 ⇒ 5 + C = 0 ⇒ C = −5
Resultado
D(10) = 5(e2 − 1) ≈ 31.95 MB

Simulador: D(t) = 5(e0.2t − 1)

Tiempo10 s
Velocidad v(t)7.39 MB/s
Descargado D(t)31.95 MB
Caso 2 · IoTAcelerómetro de un dispositivo
Situación
Un acelerómetro mide a(t) = cos(4t) m/s2 (con t en radianes). Si parte del reposo, ¿cuál es la velocidad en t = π/8?
Sustitución
u = 4t,   du = 4 dt  ⇒  dt = du4
Integrar
∫ cos u · du4 = sen u4  ⇒  v(t) = sen(4t)4 + C
Constante
v(0) = 0 ⇒ sen(0)/4 + C = 0 ⇒ C = 0
Resultado
v(π/8) = sen(π/2)4 = 0.25 m/s
Caso 3 · ServidoresSolicitudes acumuladas
Situación
Un servidor recibe solicitudes a una tasa r(t) = (2t + 1)2 solicitudes por minuto. Si en t = 0 ya había 100 acumuladas, ¿cuántas habrá en t = 3 min?
Sustitución
u = 2t + 1,   du = 2 dt  ⇒  dt = du2
Integrar
12∫ u2 du = u36  ⇒  N(t) = (2t+1)36 + C
Constante
N(0) = 100 ⇒ 1/6 + C = 100 ⇒ C = 100 − 1/6
Resultado
N(3) = 3436 + 100 − 16 = 57 + 100 = 157Son 157 solicitudes acumuladas a los 3 minutos.

6Práctica en clase

Resuelve en tu cuaderno con los cinco pasos y verifica derivando. Abre la solución solo para comparar.

P1∫ (2x + 1)3 dx Básico
Ver solución
u = 2x + 1, du = 2 dx, dx = du/2. ∫ u3 · du/2 = (1/2)(u4/4) = u4/8.
(2x + 1)4/8 + C
P2∫ sen(3x) dx Básico
Ver solución
u = 3x, du = 3 dx. (1/3)∫ sen u du = (1/3)(−cos u).
−cos(3x)/3 + C
P3∫ e5x dx Básico
Ver solución
u = 5x, du = 5 dx. (1/5)∫ eu du = eu/5.
e5x/5 + C
P4∫ 1/(4x − 1) dx Intermedio
Ver solución
u = 4x − 1, du = 4 dx. (1/4)∫ (1/u) du = (1/4) ln|u|.
(1/4) ln|4x − 1| + C
P5∫ 2x(x2 + 4)2 dx Intermedio
Ver solución
u = x2 + 4, du = 2x dx; la expresión 2x dx ya es du. ∫ u2 du = u3/3.
(x2 + 4)3/3 + C
P6Una transferencia tiene velocidad v(t) = (3t + 2)2 MB/s y parte de 0 MB. Encuentra D(t) y calcula D(2). Aplicación
Ver solución
u = 3t + 2, du = 3 dt. D(t) = (1/3)(u3/3) + C = (3t+2)3/9 + C. Con D(0) = 0: 8/9 + C = 0, C = −8/9.
D(t) = [(3t+2)3 − 8]/9
D(2) = (512 − 8)/9 = 504/9 = 56 MB.

Errores frecuentes

Olvidar dx → duNo basta con reemplazar la expresión por u; también debes convertir dx.
Dejar la respuesta en uEl resultado final debe escribirse con la variable original (x o t).
Ignorar el factor constanteEn ∫cos(5x)dx falta dividir entre 5; si lo olvidas, la derivada no regresa al integrando.
Sacar una variable de la integralSolo las constantes pueden salir; una "x" no.

Conclusión

La integración por sustitución es la regla de la cadena aplicada al revés: se elige una variable auxiliar u, se convierte dx en du, se integra con la tabla de fórmulas y se regresa a la variable original. Con las pistas para elegir u y la verificación por derivada, puedes resolver integrales como (3x+2)4, cos(5x) o 2x(x2+1)3 y aplicarlas a descargas, sensores y servidores, donde la constante de integración representa el estado inicial del sistema.
