¿Qué es un límite?

El límite de f(x) cuando x → c es el valor L al que se acerca f(x) conforme x se aproxima a c desde ambos lados. No importa si f(c) existe: el límite describe el comportamiento cercano, no el valor exacto en c.

El límite L es el valor al que converge f(x) desde ambos lados, aunque la función tenga un hueco en x = c.

Sustitución directa

Sustituye x = c. Si el resultado es un número definido (no 0/0), ese número ES el límite.

Tabla de valores

Cuando aparece 0/0, evalúa f(x) con valores cada vez más cercanos a c por ambos lados y observa hacia dónde converge.

Recuerda escribir siempre la notación completa:   lím f(x) = L   cuando x → c.
